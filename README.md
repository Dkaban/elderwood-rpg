# Elderwood

A single-player medieval fantasy RPG prototype for the browser.

**Combat Lab** is the current playable build: practice directional sword attacks against a training dummy in a quiet meadow. Includes movement controls, mobile input, combat timing adjustments, and a visual debugger for hitboxes.

[Play Elderwood](https://dkaban.github.io/elderwood-rpg/)

The earlier exploration prototype remains accessible as [Legacy Preview](https://dkaban.github.io/elderwood-rpg/legacy.html).

Built with HTML, CSS, JavaScript, and original illustrated sprite artwork. Combat Lab now uses the approved directional sword frames. No account or installation required.
